# Bugs

One markdown file per found defect, named `NNN-short-slug.md`. This is for defects found during development or manual testing that aren't yet worth a GitHub issue (or the project isn't using GitHub issues yet) — if that changes, link out instead of duplicating.

A bug fix should still go through [[tdd]]: the failing-test-first step here is the regression test that reproduces the bug.

See `TEMPLATE.md` for the expected shape.
