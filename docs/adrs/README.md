# Architecture decision records

One file per decision that changes or extends what the tech proposal already settled, named `NNN-short-slug.md`. Not for decisions the tech proposal already made (§18 "Decisions") — those stay there; an ADR is for what comes after: a reversal, a refinement, or a new decision the proposal didn't anticipate.

A `grill-me` session that reaches a settled, non-obvious decision is a natural source for one of these.

See `TEMPLATE.md` for the expected shape (lightweight MADR-style: context, decision, consequences).
