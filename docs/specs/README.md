# Specs

Feature-level specs that are more detailed than a ticket but not yet worth an ADR — typically the resolved output of a `grill-me` session on a non-trivial feature, written down before the `tdd` implementation loop starts. Named `short-slug.md`, one per feature.

Not a duplicate of the tech proposal: the tech proposal covers the system as originally planned; a spec here covers one feature's resolved design once it's been interrogated and is ready to build.
